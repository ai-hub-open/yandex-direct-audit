# v1.0.2 — журнал правок работает в Windows

Обновление с v1.0.1.

**Что исправлено.** Журнал правок — файл, по которому скилл откатывает изменения в кабинете, —
в Windows-консоли падал на русских буквах и значках ✅/⚠️. Самое неприятное: правка в журнал
записывалась, а скилл видел ошибку и мог записать её второй раз. Теперь журнал спокойно
работает в Windows: справка, запись правки, просмотр журнала и план отката выводятся читаемо.

Касается точечного режима и режима ведения при запуске в Claude Code или Cursor на Windows. В
Claude Desktop скилл работает в песочнице на Linux, там ошибки не было.

## Обновление

Скачайте новую версию скилла и замените старую (в Claude Desktop — загрузите заново в
«Настройки → Возможности → Скиллы»). Технический список изменений —
[`CHANGELOG.md`](../../CHANGELOG.md).
