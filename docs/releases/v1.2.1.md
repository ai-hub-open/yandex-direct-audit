# v1.2.1 — актуальный адрес коннектора Директа

Обновление с v1.2.0.

Коротко: если коннектор Директа не подключён, скилл теперь даёт адрес в актуальном виде click.ru.
Режимы аудита, точечных правок и ведения не менялись.

## Что изменилось для вас

**Новый вид адреса коннектора.** Нужен только токен click.ru:

```
https://direct-mcp.aihub.click.ru/c/<токен click.ru>
```

- Токен — в профиле click.ru ([click.ru/userinfo.html](https://click.ru/userinfo.html)), поле
  **API Token**.
- Закрепить один кабинет: `…/c/<токен click.ru>/<кабинет>` — логин Директа, название или ID
  в click.ru.
- Кабинет напрямую в Яндексе, без click.ru: `…/y/<OAuth-токен Яндекса>`.

Подробнее — [help.click.ru/7738](https://help.click.ru/7738).

**Уже подключённый коннектор трогать не нужно.** Старый адрес вида
`/c/<логин>/<токен>/<ID пользователя>` сервер по-прежнему принимает.

## Обновление

- **Плагин (Claude Desktop или Claude Code)** — придёт сам, если включено автообновление каталога
  `ai-hub-open`; иначе `/plugin marketplace update ai-hub-open`.
- **Архивом** — на [странице релизов](https://github.com/ai-hub-open/yandex-direct-audit/releases)
  скачайте `yandex-direct-audit.zip` из Assets этого релиза, старый скилл удалите и загрузите новый
  в **Customize → Skills**.
