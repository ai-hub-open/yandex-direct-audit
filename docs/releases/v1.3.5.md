# v1.3.5 — цифры Метрики сходятся с кабинетом

Обновление с v1.3.4.

**Что изменилось.**

- **Визиты подписаны правильно.** Метрика считает визиты по-разному в зависимости от модели
  атрибуции: по последнему значимому переходу (как в интерфейсе Метрики по умолчанию) их заметно
  больше, чем по последнему переходу. Теперь агент задаёт модель явно в каждом запросе и
  подписывает число той моделью, по которой Метрика его реально посчитала.
- **Два вопроса — два отчёта.** Сколько кликов дошли до сайта, агент считает по визитам по клику.
  Отказы, время на сайте и визиты для сверки с вашей Метрикой — по модели интерфейса Метрики.
- **Конверсии не завышены.** Конверсию и цену заявки агент берёт из Директа и не делит конверсии
  на визиты Метрики.
- **Ошибка запроса — не вывод.** Если Метрика не приняла параметр, агент не пишет «расходы
  недоступны», а сверяет имя по справочнику; не вышло — пишет об этом в ограничениях отчёта.
  Неполный ответ он догружает или прямо помечает «данные по N из M кампаний».

**Что не изменилось.** Аудит по-прежнему только читает кабинет и счётчик; деньги и конверсии —
из Директа.
