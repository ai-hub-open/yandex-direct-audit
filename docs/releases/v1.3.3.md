# v1.3.3 — агент не обещает того, чего не может

Обновление с v1.3.2.

Коротко: когда агент отказывает, он предлагает вместо этого только то, что действительно может
сделать.

## Что изменилось для вас

**1. Без права записи — без обещаний записи.** Если у агента нет доступа на изменение кабинета
(так у «Аудита Директа» на платформе AI Hub), он не предлагает «точечный режим» и не обещает
внести правки. Вместо этого — готовый список правок, которые вы внесёте в интерфейсе Директа.
Об этом он скажет одной строкой в начале работы.

**2. Пауза — только там, где она имеет смысл.** На просьбу удалить кампанию агент предложит
паузу, только если кампания показывается и он может её остановить. Черновик и так не
показывается и денег не тратит — для него агент предложит оставить всё как есть или выгрузить
содержимое перед удалением.

**Что не изменилось.** Удаление, запуск и отправку на модерацию по-прежнему делаете вы в
интерфейсе Директа. В Claude Desktop/Code, где есть права на запись, точечный режим и ведение
работают как раньше.
