# v1.2.0 — установка плагином Claude Code

Обновление с v1.1.0.

Коротко: аудит теперь можно поставить в Claude Code плагином из маркетплейса ai-hub-open — и
новые версии будут приходить сами. В Claude Desktop всё как раньше, только готовый архив теперь
лежит в релизах. Режимы аудита, точечных правок и ведения не менялись.

## Что изменилось для вас

**1. Установка плагином в Claude Code.**
Сначала подключите коннектор Директа — тот же адрес, что для Claude Desktop:

```
claude mcp add --transport http yandex-direct "<адрес коннектора>"
```

Затем в сессии Claude Code:

```
/plugin marketplace add ai-hub-open/claude-plugins
/plugin install yandex-direct-audit@ai-hub-open
```

Скилл вызывается как `/yandex-direct-audit:yandex-direct-audit` или словами: «сделай аудит
Директа». Чтобы обновления приходили сами: `/plugin` → **Marketplaces** → `ai-hub-open` →
**Enable auto-update**.

**2. Скилл сам скажет, что вышла новая версия.**
В начале разговора аудит сверяет свою версию с GitHub. Если есть новее — одним сообщением
скажет, что изменилось и как обновиться, и спросит, обновиться сейчас или продолжить. Без
интернета проверка молча пропускается. Сам себя скилл не обновляет — обновление ставите вы.

**3. Данные аудитов не пропадут при обновлении.**
Папки `direct-audits/` и `lead/` создаются в той папке, где вы работаете, а не внутри скилла.
Плагин при обновлении заменяет свою папку целиком, поэтому держать там данные клиента нельзя —
и скилл теперь это явно соблюдает.

**4. Готовый архив для Claude Desktop — в релизах.**
`yandex-direct-audit.zip` приложен к релизу, собирать его самим не нужно.

## Обновление

- **Claude Code с плагином** — как выше; дальше `/plugin marketplace update ai-hub-open`.
- **Claude Desktop** — скачайте `yandex-direct-audit.zip` из этого релиза и загрузите заново в
  Settings → Capabilities → Skills вместо старого.
- Если раньше скилл лежал папкой в `~/.claude/skills/yandex-direct-audit`, удалите её — иначе в
  Claude Code скилл загрузится дважды.
