# Правила минусации поисковых запросов и действий по фразам — ruleset

> Перенесено из скилла phrase-minus (`search-query-miner`). Исполняемая правда — `scripts/query_analyzer.py` (чистые функции) + `scripts/run_analysis.py` (CLI). Пороги настраиваются флагами. Читает субагент `search-queries` (Шаг 3) и инлайн-фолбек Шага 3.

Этот файл — доказательная база Шага 3 аудита (минусация поисковых запросов). За один прогон ядро даёт **два** результата: (A) действия по ключевым фразам по ставке/статусу и (B) минусацию запросов (минус-слова кампании + минус-фразы группы + «проверь вручную»). Скилл ничего не пишет в аккаунт — только рекомендации.

> ⚠️ **Кампании с оплатой за конверсии** (`pay_for_conversion: true` в `01_account_map.json`): действия по фразам по CPA (раздел A) и минус-фразы группы по порогу кликов без конверсий (раздел B) не применяются — клики бесплатны, цену конверсии задаёт стратегия. Минусация — только по смыслу (словарь мусора, чужое гео, конкуренты). Правила — `audit-thresholds.md` → «Оплата за конверсии».

## A. Действия по ключевым фразам (нужны конверсии и целевой CPA)

Агрегация по (кампания, ключевая фраза). База — средний CPA по кампании (расход ÷ конверсии). Пороги (флаги в скобках):

| Действие | Условие | Светофор |
|---|---|---|
| **Отключить/удалить фразу** | 0 конверсий и расход ≥ **2 × tCPA** | 🔴 `stop` |
| **Понизить ставку** | конверсии есть и CPA ≥ **1.5 × tCPA** (`--cpa-high`) | 🟠 `lower_bid` |
| **Поднять ставку + вынести в отдельную группу** | конверсии есть и CPA **ниже среднего по кампании** | 🟢 `raise_bid` |
| **Мало данных** | кликов < **30** (`--phrase-min-clicks`) и 0 конверсий | ⚪ `hold` |
| **Норма** | прочее | ✅ `keep` |

## B. Минусация запросов

Агрегация по (кампания, поисковый запрос). Каждый запрос классифицируется:

1. **Минус-слово уровня КАМПАНИИ** — запрос содержит паттерн из словаря `assets/query_patterns.json`:
   - категории: `free` (бесплатно/скачать/торрент/взлом), `info` (реферат/своими руками/как сделать/инструкция/форум/вики), `job` (вакансия/зарплата/резюме), `used` (б/у/авито/юла), `geo` (чужой город — ловится только если задан `--target-geo`), `competitor` (бренд из `--competitors`, минусуется при 0 конверсий).
   - В минус идёт рекомендованное **слово** (одно на категорию), а не каждый запрос.
2. **Минус-фраза уровня ГРУППЫ** — паттерн не распознан, но кликов ≥ **25** (`--query-min-clicks`) и 0 конверсий → минус целиком на группу (или проверь смысл).
3. **«Проверь вручную» (review)** — watch-паттерн (`отзывы` и т.п.) или конкурент без данных по конверсиям. Автоматически НЕ минусуем — решает человек.
4. **Норма (ok)** — прочее.

Оценка экономии (`saving_estimate`) — суммарный расход минусуемых запросов с 0 конверсий.

## Режим без конверсий (деградация)

Если к кампании не привязан счётчик или не настроены цели, и колонки конверсий нет (или везде 0) — запускай с `--no-conversions`:
- минусы **по паттернам** (мусор/инфо/работа/гео/конкурент) — **работают**;
- **действия по ставкам** (A) и **минус-фразы группы** (правило «≥25 кликов + 0 конверсий») — **отключены**, чтобы не наминусовать живой трафик;
- подними «алярму»: без целей оптимизация по ставкам слепая → отправь маркетолога привязать счётчик и настроить цели (это находка high на Шаге 1).

## Маппинг полей `report_search_queries` → строки ядра

Ядро ждёт: `campaign, campaign_id, ad_group, keyword, query, impressions, clicks, cost, conversions`. `run_analysis.py --input <tsv>` маппит по вхождению подстроки (регистр игнор.):

| Поле ядра | Поля отчёта (варианты) |
|---|---|
| `query` | `Query`, «Поисковый запрос» |
| `keyword` | `Criteria`, `Keyword`, «Условие показа», «Ключевая фраза» |
| `campaign` | `CampaignName`, «Кампания» |
| `ad_group` | `AdGroupName`, «Группа» |
| `clicks` | `Clicks`, «Клики» |
| `cost` | `Cost`, «Расход» |
| `conversions` | `Conversions`, «Конверсии» |

**Деньги:** коннектор отдаёт `Cost` уже в рублях — флаг денег не передавай. `--money-in-micros` нужен только для ручных выгрузок из интерфейса Директа, где суммы бывают в микрорублях.

## Куда вносит маркетолог (вручную — скилл не пишет)

- **Минус-слова кампании** (блок «Уровень КАМПАНИИ» из `minus_keywords.txt`) → Кампания → Параметры → блок «Минус-фразы». Применяется ко всем группам.
- **Минус-фразы группы** (блок «Уровень ГРУППЫ») → Группа → «Минус-фразы на группу». Запрос целиком.
- **Действия по ставкам/статусу** (`03_phrase_actions.md`) → внутри группы, на самой фразе: 🔴 отключить/удалить, 🟠 понизить ставку, 🟢 поднять + вынести в группу, ⚪ не трогать, ✅ оставить.
- **«Проверь вручную»** → реши по смыслу (есть целевая страница под запрос — оставь; нет — минусуй руками).

## Тюнинг под нишу

`--phrase-min-clicks` (дефолт 30), `--query-min-clicks` (25), `--cpa-high` (1.5). Для срочного спроса/дорогих ниш пороги кликов можно понизить; для массового дешёвого трафика — повысить. Словарь паттернов `assets/query_patterns.json` пополняй под проект (особенно `competitors` и `cities`).
